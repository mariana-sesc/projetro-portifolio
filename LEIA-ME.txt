PORTFÓLIO DE MARIANA ARRUDA OLIVEIRA VALERIO
==============================================

ARQUIVOS
- index.html: conteúdo e estrutura da página.
- style.css: cores, layout, responsividade e animações.
- script.js: interações do menu, tema, texto animado e botão de topo.

COMO ABRIR
1. Extraia o arquivo ZIP para uma pasta.
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo index.html no navegador. A extensão Live Server do VS Code
   também pode ser usada, mas não é obrigatória.
4. Para alterar textos, edite o index.html.
5. Para alterar cores, edite as variáveis no início do style.css.
6. Para alterar animações e interações, edite o script.js.
